# 💉 OpenVita DT1
**Studio Niko Design** — Application de gestion du Diabète de Type 1.

> Outil de suivi glycémique intelligent avec calculateur de bolus oref1 et intégration CGM Nightscout.

## ✨ Fonctionnalités
- Calculateur bolus oref1
- Intégration Nightscout CGM
- Base alimentaire CIQUAL 2024 (65 items)
- Glycémie en g/L (standard clinique français)

## 🛠 Stack
`HTML` · `Mistral AI` · `Nightscout API` · `Chart.js`
